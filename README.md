# JockieGuessr — o app do host

Aqui ficam só as **versões do app** do JockieGuessr (o quiz de música): o código fica em outro lugar.

Para baixar: veja a última versão em **[Releases](https://github.com/pulzi/JockieGuessr-app/releases/latest)**.

- **Linux:** `JockieGuessr-Host.AppImage` (dê permissão de execução e abra). Ele se atualiza sozinho: quando sai
  versão nova, baixa e pergunta se reinicia.
- **Windows:** `JockieGuessr-Host.exe` (portátil, sem instalar). Quando sai versão nova, o app avisa e abre esta
  página para baixar.

O placar, os perfis e as configurações ficam na pasta do app e continuam depois de atualizar.
